Privacy Policy

Last updated: 24 October 2026

Pique Up Studio ("the app") is an internal tool operated by the Pique Up channel team. It is used only to upload, schedule, and manage videos, thumbnails, titles, and descriptions on the Pique Up YouTube channel that we own.

What data the app accesses

When an authorized team member signs in with Google, the app requests YouTube API permissions (youtube.upload and youtube) for that team member's own channel. It reads basic channel information (channel ID and name) to confirm it is connected to the correct channel, and it uploads videos and metadata that the team has prepared.

How data is used and stored

  • OAuth tokens are stored only on the team's own computer and are used only to call the YouTube Data API on behalf of the Pique Up channel.
  • We do not collect, sell, share, or transfer any user data to third parties.
  • We do not use Google user data for advertising or for training AI models.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The app uses YouTube API Services. By using it you also agree to the YouTube Terms of Service. See the Google Privacy Policy. You can revoke the app's access at any time at myaccount.google.com/permissions.
